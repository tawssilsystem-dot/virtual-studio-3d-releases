# VIRTUAL STUDIO 3D — téléchargements

Ce dépôt contient uniquement les **versions publiées** de VIRTUAL STUDIO 3D (installateurs Windows). Le logiciel installé l'interroge pour ses mises à jour automatiques. Le code source n'est pas public.

## Installer
1. Ouvrez l'onglet **[Releases](../../releases/latest)** et téléchargez `VirtualStudio3D-Setup-<version>.exe`.
2. Lancez-le (aucun droit administrateur requis).

> L'installateur n'est pas encore signé numériquement : Windows SmartScreen peut afficher « Windows a protégé votre ordinateur ». Cliquez sur *Informations complémentaires*, puis *Exécuter quand même*.

## Mises à jour
Le logiciel vérifie automatiquement ce dépôt et télécharge les nouvelles versions en arrière-plan. Il propose ensuite **Redémarrer et installer**.

Configuration requise : Windows 10 ou 11, 64 bits.
